# case-intelligence Web UI SPEC

## 概述

基于 Streamlit 的 Web UI，提供案件管理、扫描录入、文书生成、统计看板功能。

## 技术方案

### 目录结构

```
case-intelligence/
├── app.py                    # Streamlit 主入口（多页应用）
├── config.py                  # UI 配置
├── SPEC.md                    # 本文档
├── ui/
│   ├── __init__.py
│   ├── auth.py              # 登录认证
│   ├── config.py            # 页面配置
│   └── utils.py             # 工具函数
└── pages/
    ├── 1_登录.py
    ├── 2_案件列表.py
    ├── 3_扫描录入.py
    ├── 4_文书生成.py
    └── 5_统计看板.py
```

### 认证配置

```python
# config.py
USERS = {
    "admin": "admin123",
    "test": "test123",
}
```

### 端口

- 默认: 18503
- 备用: 18504

## M1: 登录 + 案件列表

### 功能

#### 登录页
- 用户名/密码输入
- 登录按钮
- 错误提示
- 登录状态持久化（session_state）

#### 案件列表页
- 搜索框（按案号/原告/被告搜索）
- 案件卡片列表
  - 案件名称
  - 案号
  - 原告/被告
  - 状态标签（pending/extracted/archived）
  - 健康度指示
  - 提取物数量
- 分页（每页20条）
- 点击进入详情

## M2: 扫描录入

### 功能

#### 扫描录入页
- 路径输入框（手动输入目录路径）
- 扫描按钮
- 实时显示扫描结果
- 确认导入按钮
- 扫描历史（最近5条）

### 流程

1. 用户输入路径
2. 调用 `scanner.scan_directory()`
3. 显示发现的文件列表
4. 用户确认后调用 `extractor.extract_case()`
5. 调用 `importer.import_full()`
6. 显示导入结果

### 验收

- [x] 路径输入正常
- [x] 扫描结果显示正确
- [x] 导入成功
- [x] 案件列表更新

## M3: 文书生成

### 功能

#### 文书生成页
- 案件选择下拉框
- 文书类型选择（答辩状/质证意见/当庭陈述/证据目录）
- 生成按钮
- 预览区域（Markdown渲染）
- 导出按钮（DOCX/MD）

### 流程

1. 选择案件
2. 选择文书类型
3. 点击生成
4. 调用 `langchain_llm.generate_direct()`
5. 显示预览
6. 可导出

## 通用规范

### 登录保护
- 除登录页外，其他页面需登录后访问
- 未登录自动跳转登录页

### 错误处理
- 所有操作显示成功/失败提示
- 失败显示具体错误信息

### 样式
- 使用 Streamlit 原生组件
- 简洁实用的布局
- 状态用颜色区分（pending=黄，extracted=绿）
