# 证据三级分类清单

## 适用场景
著作权侵权案件中，被告提交证据时的目录编制与三级分类管理

## 模板结构

### 一、核心证据（第一级）
直接证明被告已取得合法授权或原告主体不适格

**示例：**
- 证据1：音集协授权许可协议（证明已取得集体管理授权）
- 证据2：音著协词曲授权协议（证明已取得词曲授权）
- 证据3：音集协缴纳凭证（证明已履行付费义务）

### 二、辅助证据（第二级）
证明被告主观无过错或已尽合理注意义务

**示例：**
- 证据1：KTV行业惯例授权资料（证明行业通行模式）
- 证据2：被告内部版权审查流程文件（证明已尽审查义务）
- 证据3：行业媒体报道（证明行业认知状态）

### 三、补充证据（第三级）
用于应对法庭追问或补充论证

**示例：**
- 证据1：同类案件判决书（证明判赔惯例）
- 证据2：专家意见（证明专业认知）
- 证据3：其他参考材料

## 证据目录格式

| 序号 | 证据名称 | 证明目的 | 证据类型 | 页码 |
|------|---------|---------|---------|------|
| 1 | | | 核心/辅助/补充 | |
| 2 | | | 核心/辅助/补充 | |

## 使用原则
- 核心证据必须完整、充分
- 辅助证据与核心证据相互印证
- 补充证据按需提交，避免堆砌
