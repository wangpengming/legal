# 新案匹配：相似案源检索

> **版本**: 1.0.0 | **更新**: 2026-09-22
> **用途**: 根据新案特征，在 Artifact 知识库中匹配相似案件
> **输入**: 新案基本信息（案号/原告/被告/案由/涉案场景/授权状态）
> **输出**: 相似案件排序列表 + 相关 Artifact 清单

---

## 使用方法

1. 输入新案基本信息
2. AI 根据匹配维度检索知识库
3. 输出相似案件 + 建议参考的 Artifact

---

## 匹配维度（按权重排序）

| 权重 | 匹配维度 | 说明 |
|------|---------|------|
| P0 | **被告授权状态** | 是否已取得集体管理授权（最关键） |
| P1 | **涉案场景** | 实体KTV / 车载KTV / 线上平台 |
| P2 | **案由类型** | 著作权侵权 / 合同纠纷 / 追偿权 |
| P3 | **原告授权层级** | 原始权利人 / 独家被授权 / 间接授权（2级+） |

---

## 匹配算法

```
1. 构建新案画像标签
   新案标签 = {
     被告授权状态: "已获音集协授权" / "未获授权" / "部分授权",
     涉案场景: "实体KTV" / "车载KTV" / "线上平台" / "其他",
     案由类型: "著作权侵权" / "合同纠纷" / ...,
     原告授权层级: "原始权利人" / "独家授权" / "间接授权2级+" / "集体管理",
   }

2. 在知识库中匹配
   - 完全匹配（P0+P1+P2+P3）：⭐⭐⭐⭐⭐ 极高相关
   - 高度匹配（P0+P1+P2）：⭐⭐⭐⭐ 高度相关
   - 中度匹配（P0+P1）：⭐⭐⭐ 中度相关
   - 弱匹配（P0）：⭐⭐ 弱相关

3. 输出结果
```
