# 跨案归纳：Artifact 汇聚

> **版本**: 1.0.0 | **更新**: 2026-09-22
> **用途**: 从多个同类案件的 Artifact 中归纳通用结构，生成可复用的模板
> **触发条件**: 同类案件 ≥ 3 个时，可进行跨案归纳

---

## 使用方法

1. 收集同类案件的同维度 Artifact（如 3 个案件的 D3 攻防策略）
2. AI 分析共性与差异
3. 归纳通用结构
4. 输出可复用的模板

---

## 输入格式

```markdown
## 案件1：[案件名称] 的 D3 攻防策略
[artifact 内容]

---

## 案件2：[案件名称] 的 D3 攻防策略
[artifact 内容]

---

## 案件3：[案件名称] 的 D3 攻防策略
[artifact 内容]
```

---

## 归纳步骤

### Step 1: 共性提取

```
分析三个案件的 D3 攻防策略，找出：
1. 共同的核心论点
2. 相似的论证结构
3. 相同的法律依据
```

### Step 2: 差异分析

```
分析三个案件的差异点：
1. 哪些是案件特有的？
2. 哪些可以泛化？
```

### Step 3: 通用结构归纳

```
基于共性，归纳通用结构：
- 适用于什么类型的案件？
- 核心论点是什么？
- 论证结构是什么？
- 适用条件是什么？
```

---

## 输出格式

```markdown
# [维度名称] 通用模板

## 适用条件
- 适用于：[案件类型描述]
- 不适用于：[排除条件]

## 核心论点
（跨案件归纳的共同论点）

## 论证结构
### （一）[第一层论点]
### （二）[第二层论点]
### （三）[第三层论点]

## 法律依据
- [共用的法条]

## 证据要求
- [需要哪些证据支撑]

## 注意事项
- [跨案件的注意事项]
```
