# 跨案归纳：抗辩论证链通用模板（D3）

> **版本**: 2.0.0 | **更新**: 2026-09-22
> **目的**: 从 2+ 同类案件归纳通用论证结构，形成可复用的 D3 模板
> **数据来源**: 腾讯案 D3 + 广电案 D3

---

## 角色定义

你是一位资深民商法律师，擅长从历史案件中归纳通用论证结构。
你必须严格遵循"跨案归纳法"，将多个同类案件的论证结构提炼为可复用的模板。

## 一、归纳方法

从以下 2 个案件的 D3 artifact 中提取通用结构：

| 案件 | D3 Artifact | 主战场 | 论证结构 |
|------|------------|--------|---------|

## 二、通用结构：抗辩论证链四步法

### 核心发现

**无论案件类型，抗辩论证链均遵循同一底层结构**：

```
第一步：事实层（干了什么）
   ↓
第二步：法律层（怎么定性）
   ↓
第三步：论证层（为什么是对的）
   ↓
第四步：结论层（带来什么后果）
```

### 通用模板

```markdown
## [抗辩名称]

### 核心论点
[一句话概括被告的核心立场]

### 法律依据
- [法条1]（[条款名称]）：[简要说明]
- [法条2]（[条款名称]）：[简要说明]

### 论证结构

#### 第一步：[事实层]
[具体事实描述]
- 事实：___________________________
- 来源：___________________________

#### 第二步：[法律层]
[法律如何定性]
- 法律：___________________________
- 分析：___________________________

#### 第三步：[论证层]
[为什么被告是对的]
- 论点1：_________________________
  - 支撑：_________________________
- 论点2：_________________________
  - 支撑：_________________________

#### 第四步：[结论层]
[对案件结果的影响]
- 结论：___________________________
- 效果：___________________________
```

## 三、具体模板（从真实案例归纳）

### 模板A：主体不适格论证（来自腾讯案）

```markdown
## 主体不适格四层递进论证

### 核心论点
原告就[涉案场景]的[权利类型]不具有诉讼主体资格

### 法律依据
- 《著作权集体管理条例》第19条：集体管理组织可以自己的名义为会员维权
- 《著作权集体管理条例》第20条：被授权方应在授权范围内行使权利

### 论证结构

#### 第一步：集体管理组织已取得授权
- 事实：[集体管理组织名称]已对涉案作品取得集体管理授权
- 事实：[集体管理组织名称]已对涉案作品实际行使集体管理职能

#### 第二步：授权范围重叠
- 事实：原告主张的权利范围与[集体管理组织名称]集体管理范围重叠
- 分析：被告使用行为落在集体管理组织授权范围内

#### 第三步：原告主体不适格
- 论点：原告为非集体管理主体，无权独立主张集体管理范围内的权利
  - 论点1：原告授权链为[2级+间接授权]，非原始权利人
  - 论点2：原告非独家被授权方，无权单独维权
  - 论点3：根据《著作权集体管理条例》第19条，集体管理组织可以自己的名义维权

#### 第四步：结论（釜底抽薪）
- 结论：原告主体不适格，应裁定驳回起诉
- 效果：一击KO，无需审查侵权事实

### 适用条件
- 原告授权链 ≥ 2级
- 涉案场景属于集体管理范围（KTV/车载KTV/线上平台）
- 集体管理组织已对涉案作品实际行使管理职能
```

### 模板B：授权合法+主观无过错论证（来自广电案）

```markdown
## 主观无过错四点论证

### 核心论点
被告已取得合法授权，主观无过错，依据《著作权法》第54条应减轻责任

### 法律依据
- 《著作权法》第54条：侵权赔偿与侵权情节相当，故意侵权才适用惩罚性赔偿
- 最高法著作权司法解释：法定赔偿应综合考虑主观过错、侵权情节等因素

### 论证结构

#### 第一步：被告已取得合法授权
- 事实：被告已与[音集协/音著协]签订许可协议
- 事实：被告已按协议约定支付许可费用
- 事实：这是[行业名称]数十年来全部通过集体管理组织获得授权的惯例行为

#### 第二步：被告已尽合理注意义务
- 论点：签订许可协议 + 定期续签 + 协议到期前主动推进补充授权
- 论点：双重保障（音集协授权 + 音著协词曲授权）体现了高度注意标准

#### 第三步：被告主观为善意
- 论点：权利人数量庞大（数十万首作品+众多权利人）
- 论点：集体管理状态动态变化，无统一公示机制
- 论点：逐一核查超出被告专业能力和合理成本范围

#### 第四步：结论
- 结论：被告主观无过错，依据《著作权法》第54条应大幅减轻责任
- 效果：即使认定侵权，赔偿数额应在法定赔偿下限附近酌定

### 适用条件
- 已与音集协/音著协签约并付费
- 行为符合行业惯例
- 涉案场景：KTV/车载KTV/线上平台
```

## 四、模板选择决策树

```
新案信息
   ↓
提取：原告授权层级 + 被告授权状态 + 涉案场景
   ↓
原告授权链 ≥ 2级？
   ├─ 是 → ✅ 选"模板A：主体不适格"（一击KO）
   │        优先：釜底抽薪
   └─ 否 → 被告已获集体管理授权？
            ├─ 是 → ✅ 选"模板B：授权合法+主观无过错"
            │        辅助：赔偿数额抗辩
            └─ 否 → ⚠️ 抗辩空间有限，仅能打侵权事实本身
   ↓
无论选哪个模板，最后都加上：
✅ 赔偿数额抗辩（传播范围有限 + 已付对价 + 法定赔偿下限）
```
