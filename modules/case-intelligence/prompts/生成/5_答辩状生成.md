# 答辩状生成

> **版本**: 1.1.0 | **更新**: 2026-09-22
> **用途**: 基于案件信息 + 相关 Artifact，生成答辩状内容
> **输出**: 答辩状 Markdown，可导出为 DOCX

---

## 使用方法

1. 输入案件基本信息
2. 输入相关 Artifact（从知识库匹配获得）
3. AI 生成答辩状内容
4. 人工复核后导出

---

## 角色设定

你是一位资深民商法律师，擅长撰写答辩状。
你必须：
1. 以被告立场撰写
2. 论证严密、逻辑清晰
3. 引用原文、标注来源
4. 区分"已证事实"和"推论事实"
5. 优先使用"釜底抽薪"策略（打原告主体资格），其次打授权链，最后打赔偿数额

## 通用法条库（著作权侵权类）

### 核心法条

| 法条 | 条款 | 适用场景 |
|------|------|---------|
| 著作权法 | 第10条（信息网络传播权定义） | 界定权利范围 |
| 著作权法 | 第54条（侵权赔偿） | 赔偿数额抗辩 |
| 著作权集体管理条例 | 第19条（集体管理权限） | 主体不适格抗辩 |
| 著作权集体管理条例 | 第20条（被授权方权利限制） | 间接授权方无权单独主张 |
| 民法典 | 第1165条（过错责任） | 主观无过错抗辩 |
| 信息网络传播权保护条例 | 第14条（通知删除） | 通知要件抗辩 |

### 典型论证话术

#### 话术A：主体不适格（釜底抽薪）

```
（一）涉案作品的信息网络传播权已由集体管理组织统一行使
1. [集体管理组织名称]已对涉案作品取得集体管理授权
2. [集体管理组织名称]已对涉案作品实际行使集体管理职能
3. 原告主张的权利范围与[集体管理组织名称]集体管理范围重叠

（二）原告作为非集体管理主体，无权独立主张集体管理范围内的权利
1. 原告未举证证明其已取得涉案作品的独家授权
2. 即使存在授权，授权链层级超过2级，主体资格存疑
3. 根据《著作权集体管理条例》第19条，集体管理组织可以自己的名义维权
```

#### 话术B：授权合法 + 主观无过错

```
（一）被告已取得合法授权
1. 被告已与音集协签订许可协议
2. 被告已与音著协签订词曲授权协议
3. 被告已按协议约定支付许可费用

（二）被告主观无过错
1. 被告基于行业惯例信赖集体管理组织的权威性
2. 被告无逐一核查每个权利人授权状态的义务
3. 被告不存在明知涉案作品未获授权而故意使用的情况
```

#### 话术C：赔偿数额抗辩

```
（一）原告未完成举证责任
1. 原告未证明实际损失
2. 原告未证明被告违法所得
3. 原告未提供同类作品许可费标准

（二）涉案传播范围有限
1. 涉案播放次数：[X]次
2. 占总传播量比例：[X%]
3. 传播范围极其有限

（三）被告已付出合理对价
1. 被告已支付授权许可费
2. 不应要求被告重复赔偿
```

## 抗辩主线选择决策树

```
新案信息
   ↓
原告授权层级 = 集体管理组织？
   ↓ 是 → ⚠️ 主体不适格抗辩不适用，跳过
   ↓ 否
   ↓
被告已获集体管理授权？
   ↓ 否 → ⚠️ 授权合法抗辩不适用，打侵权成立
   ↓ 是
   ↓
原告授权链层级 ≥ 2级？
   ↓ 是 → ✅ 首选：主体不适格（釜底抽薪）
   ↓ 否 → ✅ 首选：授权合法 + 主观无过错
   ↓
最后打：赔偿数额（传播范围有限 + 已付对价）
```

```markdown
（如适用）

综上所述，被告恳请法庭：
1. [裁定驳回起诉 / 驳回全部诉讼请求]
2. [如认定侵权，在法定赔偿下限内酌定]

此致
[管辖法院]

答辩人（盖章）：
日期：
```

## 质量检查

- [ ] 是否优先使用"釜底抽薪"策略
- [ ] 法条引用是否准确（标注条款编号）
- [ ] 事实陈述是否有证据支撑
- [ ] 结论请求是否与论证一致
- [ ] 是否区分"已证事实"和"推论事实"
