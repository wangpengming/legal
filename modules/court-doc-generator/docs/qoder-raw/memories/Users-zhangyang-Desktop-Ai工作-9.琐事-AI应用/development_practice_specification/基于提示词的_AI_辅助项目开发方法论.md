AI 辅助项目开发全流程技能 · 提示词反推方法论
- 核心原则：每个提示词都是“可独立发出去让 AI 执行”的，小白可按顺序一步步推进
- 五阶段推进法：0 业务理解 → 1 MVP 启动 → 2 核心功能 → 3 服务化部署 → 4 UI 体验 → 5 故障排查
- 提示词结构：背景 + 任务 + 验收标准 + 避坑指南，确保每步可验证
- 适用场景：从 0 开始开发新工具、借鉴现有项目路径、培训新人快速上手、二次开发扩展功能
