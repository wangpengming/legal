## 输入
- macOS 下的 `.command` Shell 脚本文件
- 需求：双击运行后终端窗口不立即关闭，以便查看输出或错误信息

## 步骤
1. **移除 `exec` 关键字**：原脚本若使用 `exec script.sh`，当前 shell 会被替换，导致父进程结束窗口关闭；改为直接调用 `./script.sh`。
2. **添加交互等待**：在脚本末尾添加 `read -p "按回车键关闭窗口..."`，强制脚本暂停直到用户输入。
3. **保留退出码**：记录子脚本的 `$?` 并在最后 `exit $EXIT_CODE`，确保状态正确传递。

## 输出
双击 `.command` 后终端窗口保持打开，显示完整日志，用户确认后可手动关闭。

## 注意事项
- macOS 双击 `.command` 默认行为是执行完毕后立即销毁终端窗口。
- `read` 命令在非交互式环境（如某些自动化测试）中可能阻塞，需根据场景决定是否保留。
