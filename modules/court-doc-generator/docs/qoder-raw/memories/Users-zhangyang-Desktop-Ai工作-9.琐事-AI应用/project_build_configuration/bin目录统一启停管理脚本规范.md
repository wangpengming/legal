项目需在bin目录下提供统一的启动管理脚本：包含Linux sh脚本和Windows bat脚本；保留原有command启动方式位置不变；所有脚本须支持启停、重启、状态查询功能，且管理逻辑同时支持基于PID和基于服务名称两种识别方式。
