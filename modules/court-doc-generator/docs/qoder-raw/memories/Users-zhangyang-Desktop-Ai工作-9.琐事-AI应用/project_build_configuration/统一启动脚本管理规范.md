项目需提供统一的启动脚本管理能力：在`bin/`目录下提供`.sh`（Linux/macOS）和`.bat`（Windows）脚本，支持按服务名称和PID进行启停、重启、状态查询等操作；当前`启动.command`位置保持不变。
