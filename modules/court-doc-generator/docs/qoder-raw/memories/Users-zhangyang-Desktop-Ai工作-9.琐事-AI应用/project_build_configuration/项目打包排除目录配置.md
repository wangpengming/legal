项目打包分发使用 zip 命令，需排除以下目录：
- `.venv/` (虚拟环境)
- `outputs/` (历史生成文件)
- `.run/` (PID和日志)
- `__pycache__/` (编译缓存)
- `static/merged/` (静态资源缓存)
- `data/` (数据库文件)
