应用启动方式：
- macOS 推荐：双击项目根目录的 `启动.command`
- 命令行：`bash bin/manage.sh start` 或 `bash bin/start.sh`
- 服务端口：固定为 18501
- 日志路径：`.run/streamlit.log`
- 环境要求：Python 3.9+
