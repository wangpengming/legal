出庭手续生成器 · 核心功能与技术方案
- 业务目标：一键生成 7 份出庭材料（法定代表人证明/授权委托书/推荐信 +4 份固定证件），合并 PDF，打包 ZIP
- 技术栈：Streamlit 前端 + python-docx 处理 Word + pypdf/PyMuPDF 处理 PDF + SQLite 数据库
- PDF 浏览器预览方案：PDF.js 全内联 base64 data URI，绕过 Streamlit SPA 路由拦截与 CDN 限制
- 关键实现：Worker 通过 Blob URL 注入，主库用 eval(atob(mainB64)) 而非 new Function()，避免变量泄漏问题
- 服务管理：bin/manage.sh 统一入口，三重进程定位（PID+ 端口 + 进程名），健康检查 curl /_stcore/health
