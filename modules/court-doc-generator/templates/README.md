## 二、占位符规范（极其重要）

### 2.1 字符

- **必须使用中文全角【】**（U+3010 U+3011），**禁止** 用英文 `[]`、`< >`、`{{ }}` 等
- 每个 `【】` 是一个占位符，等长替换为 1 个值

### 2.2 替换顺序

> **按【】在文档中从左到右、从上到下的物理出现顺序** 依次替换。

示例：

```
模板：兹证明【】系【】的法定代表人。
values = ["马杰", "北京雷石天地电子技术股份有限公司"]
结果：兹证明马杰系北京雷石天地电子技术股份有限公司的法定代表人。
```

## 三、制作/修改模板的操作步骤

### 3.1 新建模板

1. 用 Microsoft Word / WPS / Pages 创建 `.docx`
2. 按上表填入占位符 `【】`
3. 保存到本目录，文件名严格匹配上表
4. 用 `unzip -p "2.法定代表人证明.docx" word/document.xml | grep -o '【】' | wc -l` 验证占位符数量
5. 在 `tests/test_placeholder.py` 加一个测试用例

### 3.2 修改现有模板

1. 不要手动重排版（可能破坏段落 runs 结构）
2. 仅在【】位置填入真实日期/案号字段
3. 修改后跑回归测试：`pytest tests/`

### 3.3 验证占位符替换正确

```bash
cd /Users/pengming/code/me/legal/modules/court-doc-generator
pytest tests/test_placeholder.py -v
```

## 四、避坑指南

| 坑 | 现象 | 解决 |
|----|------|------|
| 用了英文 `[]` | python-docx 不识别，【】被忽略 | 全局替换：`[]` → `【】` |
| 占位符被 Word 拆成多段 | 看似 1 个【】实则 2 个 | **不用管**，python-docx 自动合并 runs |
| 占位符数 < values 数 | 后续值不替换，正常 | **正常行为**（多给无害） |
| 占位符数 > values 数 | 多余占位符留空 | **正常行为**（少给也无害，缺失填空串） |
| 表格内占位符 | python-docx 支持 | **正常**，会自动遍历表格单元格 |
| 模板里有图片 | 图片保留，【】仍替换 | **正常**，只替换文本不删图 |
