# 设计验收清单（Design Acceptance Checklist）

> 版本：v1.0 ｜ 日期：2026-08-13 ｜ 状态：**已通过（2026-08-13 签核放行）**
>
> **用途**：对 `docs/prototypes/` 12 个高保真 HTML 原型页 + 共享设计系统的逐页验收依据。
> **门槛**：全部勾选框为 ✓ 且验收记录签字后，方可进入开发（开发规格以 `02-详细设计-前端.md` / `03-详细设计-后端.md` 为准，原型仅作视觉与交互基准）。

## 0. 验收操作方法

1. 用浏览器直接打开 `docs/prototypes/00-index.html`（无需构建、无外部依赖，仅引用 `assets/prototype.css`）。
2. 逐页按本清单核对：**视觉**（对照 02-详细设计 §样式规范）、**数据**（对照本清单「数据真值」列）、**交互**（逐项点击/切换）。
3. 勾选规则：
   - ✓ = 通过（完全符合通过标准）
   - ✗ = 不通过（记录差异描述，回到原型修改后复验）
   - – = 豁免（明确合理的降级项，需备注原因）
4. 全部通过后在文末签核，并将结论回填交付物索引。
