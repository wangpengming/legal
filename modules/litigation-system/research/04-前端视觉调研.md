> 结论摘要: shadcn/ui token 化双主题 + 数据密度 BI 风 + 语义状态色（占优/判赔/待定）+ 全站检索/AI 对话面板

## 1. 视觉方向定位

参考对象与风格锚点：

| 参照 | 风格特征 | 用到哪 |
|------|----------|--------|
| shadcn/ui（ui.shadcn.com）+ 官方 themes | token 化（CSS 变量）双主题、克制、组件一致性强 | 全局设计系统、组件基座 |
| 简道云/元典/律杏等法务系统 | 专业蓝商务感、表格密度高、看板直白 | 页面骨架、看板布局 |
| Metabase / Grafana / BI 产品 | 数据密度、微图表、下钻交互 | 表格、图表、分析页 |
| iCourt/民生智库画像卡 | 人物/实体画像卡片布局 | S4 对手方画像页 |
| Assistant UI（shadcn 生态对话组件） | AI 对话面板、打字流、来源脚注 | AI 对话面板（Mode A） |

**一句话定位**：专业克制的「数据密度型」B 端工具——**不是营销页审美，不是低代码表格壳**；让 638 条数据在 1080p 下「一目十行、秒级下钻」。

## 2. 设计令牌（Design Tokens）草案

### 2.1 色板（语义驱动，双主题共用语义层）

| 语义 | 亮色 | 暗色 | 用途 |
|------|------|------|------|
| primary（法务蓝） | #2563EB | #3B82F6 | 主操作、选中、链接（商务专业感） |
| success（我方占优） | #16A34A | #22C55E | 结案原因=胜诉/驳回对方诉求/撤诉占比高 |
| danger（判赔/风险） | #DC2626 | #EF4444 | 判赔、超期未结、终本新警 |
| warning（待定/执行） | #D97706 | #F59E0B | 和解待定、执行中、终本 |
| info（中性提示） | #64748B | #94A3B8 | 待定口径、无依据标记 |
| bg / surface / border | 灰阶层级（slate 系） | reverse | 布局与层级 |

> 语义色与「结案原因/案件状态枚举」绑定规则（写入 docs/02 §状态色映射表），全站一处定义、处处一致。

### 2.2 字体与排版

| 项 | 规范 |
|----|------|
| 西文/数字 | Inter（等宽数字特征）或用系统栈 -apple-system/Inter |
| 中文 | 思源黑体 fallback（PingFang SC / Microsoft YaHei） |
| 数字专用 | tabular-nums（表格金额对齐 KEY） |
| 字号梯度 | 11/12/13/14/16/20/24（数据表 12~13px，标题 16~20px，大数字 24px+） |

### 2.3 布局与圆角

| 项 | 规范 |
|----|------|
| 基准单位 | 4px 栅格；内容区左右 20px；卡片 gap 12~16px |
| 圆角 | 标题卡 12px / 控件按钮 8px / 徽标 pill |
| 阴影 | 两层：card（低）浮层（高，含 8px 模糊 + 1px 边框） |
| 行高 | 数据表 28px（紧凑）/ 32px（舒适，可切） |

### 2.4 动效

- 仅功能性动画：卡片数字滚数（≤600ms）、图表过渡（≤400ms ease-out）、抽屉/弹层 200ms、加载骨架屏（无旋转圈）；
- 禁止花哨：无弹跳、无无限旋转、无自动轮播。

## 3. 组件基座（shadcn/ui + 扩展）

| 场景 | 组件（shadcn 原生/扩展） |
|------|--------------------------|
| 布局 | Sidebar（折叠 240/64px）+ Topbar（全局检索 + 同步状态 + 主题切换） |
| 数据表 | TanStack Table headless + shadcn Table 样式：固定首列、列显隐、虚拟滚动、行内微图表（Sparkline） |
| 筛选 | 组合筛选面板（字段枚举字典驱动）+ 保存筛选集 + URL 同步（可分享/可退回） |
| 看板卡 | StatCard（数字 + 环比 + 下钻链接 + 口径 tooltip） |
| 图表 | ECharts 封装：柱堆叠/折线/热力/饼/树（下钻联动，tooltip 带口径脚注） |
| 画像卡 | ProfileCard（头像位/实体名/关键指标网格/时间线） |
| AI 对话 | Assistant-style 面板：气泡、打字流、来源脚注可折叠、追问建议 chips |
| 状态 | 同步状态条（成功/进行中/失败+重试）、脏数据角标（Badge）、空态/错误态组件 |
| 主题 | ThemeProvider（亮/暗）+ 主题 token 同步 CSS 变量 |

## 4. 关键交互模式（设计定稿依据）

1. **全站检索**：Topbar 搜索框 + `/` 快捷键；键入即下拉联想（案号/当事人/歌曲/案由预制）；Enter 进检索页；
2. **表格↔图表联动**：表格选中/筛选变化 → 图表重渲染；点图表柱子 → 回填筛选条件到表格（双向）；
3. **数字下钻**：所有统计数字可点击 → 弹出「明细抽屉」（列表 + 口径脚注），杜绝「只给结论不给依据」；
4. **原始/清洗对照**：详情页字段旁「raw 徽标」→ hover 显示原始值 tooltip，或整页「原始视图」开关；
5. **AI 回答带三源脚注**：每条结论下面列出「本地库 N 条 / 案例库 M 条 / 法条 K 条」与链接（调研 01/02 结论的 UI 落实）；
6. **空/错/脏状态**：空态给「为何为空 + 下一步」；同步失败置顶红色条 + 重试；脏数据字段角标提示清洗进度。

## 5. 响应式与多分辨率

- 主目标 1440×900 ~ 1920×1080；最小支持 1280 宽（侧栏可折叠给内容）；
- 表格横向滚动 + 首列固定；看板卡在 <1440 自动 2 列排布；
- 打印友好：报告/详情可导出打印样式（@media print 隐藏侧栏/交互控件）。

## 6. 结论（写回 docs/02 详细设计）

| 项 | 结论 |
|----|------|
| 主题 | shadcn 双主题 token（语义色 + slate 灰阶 + tabular-nums） |
| 密度 | 表格 12~13px + 28px 行高 + 紧凑列宽，数字对齐 |
| 组件 | shadcn 基座 + TanStack Table + ECharts + Assistant 风格对话面板 |
| 交互 | 全站检索、表图联动、数字下钻、原始/清洗对照、三源脚注 |
| 状态 | 同步状态条全局、脏数据角标、空错态组件齐全 |
| 动效 | 功能性动画为主（滚数/过渡/骨架屏），无装饰动画 |
