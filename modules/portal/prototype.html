🎯 定位

法务部门统一门户（门面 + 健康监控）与子系统集成框架。四个数字：统一入口、品牌门面、注册表驱动、健康监控。

📦 注册表驱动（apps.yaml）

  • 导航、欢迎页卡片、健康卡片、子系统视图全部由注册表动态渲染
  • 新增模块 = 注册表加一行 + nginx 加一段反代 → 即插即用
  • 左侧菜单与modules/index.yaml同源同思想

🔌 异构兼容策略

  • Streamlit / NocoDB / Paperless 等黑盒 Web 应用 → nginx 同源反代 + iframe
  • React 同栈子系统（litigation-system）→ 后续可演进为微前端原生嵌入

商务蓝 #1F3A93 / #2B5BCE · 金色点缀 #B7984D · 印章红告警 #C0392B · 浅色留白 · 庄重耐看。
