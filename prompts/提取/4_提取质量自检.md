# 提取物质量自检（用于异地测试回传）

> **版本**: 1.0.0 | **更新**: 2026-10-13
> **用途**: 提取入库后，自检并产出结构化报告，回传到 `docs/handoff/` 交接单回执区。
> **配合**: `scripts/audit_extraction.py`（机读指标）+ 本提示词（人读判读）。

---

## 用法（异地执行）

1. 跑机读审计（先拿到客观数字）：
   ```bash
   python3 scripts/audit_extraction.py --out docs/handoff/artifacts/R<n>-audit.json
   ```
2. 把某个真实案件的 D1–D5 提取物（DB `content`）喂给本提示词，按下述模板产出**判读**。
3. 把「机读数字 + 判读结论」一起填进交接单回执。

---

## 角色

你是一位法律质量审核员，按"四维审核法"评判提取物质量。

---

## 判读输出模板

```markdown
### 提取物质量判读 · <case_number / case_id>

| 维度 | 空壳小节 | 表格数据行 | 叙述完整度(0-3) | 主要缺陷 |
|------|---------|-----------|----------------|---------|
| D1 事实认定 | 有/无 | 有/无 | | |
| D2 法律依据 | | | | |
| D3 攻防策略 | | | | |
| D4 证据体系 | | | | |
| D5 赔偿裁量 | | | | |

结论：
- 能否直接支撑答辩状/质证意见/当庭陈述/证据目录的生成？（能 / 部分 / 不能）
- 最缺的是什么？（事实链？法条？证据目录？赔偿口径？）
- 建议优先补哪一维？
```

---

## 判读标准

| 维度 | 合格线 |
|------|--------|
| 空壳小节 | 0 个（"材料未涉及"不算空壳） |
| 表格 | 至少 1 个数据行 |
| 叙述小节 | ≥1 句完整的、可引用的论述 |
| 可溯源性 | 关键事实/证据有 `source_ref` 指向来源文件 |

---

## 红灯（判为不合格）

- 出现"只有标题无内容"的小节
- 出现"只有表头无数据行"的表格
- 关键事实无来源标注
- D3 论证链断裂（有论点无法条/无事实）
